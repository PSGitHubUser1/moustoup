# moustoup

This script allows you to check if your external mouse is plugged/unplugged.

When mouse is plugged-in, when you press 'SUPER + F10', the touchpad will disable

&ensp;&ensp;&ensp;&ensp;&ensp;&ensp;&ensp;&ensp;&ensp;&ensp;&ensp;&ensp;&ensp;&ensp;&ensp;&ensp;OR

If mouse is unplugged, pressing same keybind will turn on touchpad.
